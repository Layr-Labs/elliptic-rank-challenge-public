# A smaller new curve in the full-2-torsion rank-13 cell

## Result and scope

This submission adds one independently generated specialization of the X400a
family at the fresh parameter T = 35213/16986. The official local verifier
certifies 13 independent rational points of infinite order and torsion group
Z/2Z x Z/2Z on its minimal integral model. Its naive height is 25.818611.
The previous promoted holder of this cell has height 26.418419. The frozen
baseline for this cell is 28.082546.

The verified board total increases from 109.84323118123126 to
111.9791058985735. The local improvement is 2.135874717342233 points.
Only the cell 2x2/13 improves: its contribution rises from
5.925840912002781 to 8.061715629345004. This is a certified rank lower bound;
the point count and the verifier establish rank at least 13. A separate
PARI/GP descent in this search returned bounds [13,13].

The new scored file is
submission/board/first-t2x2-p35213-q16986-r13.ec.
All 23 inherited board files remain byte-for-byte unchanged relative to the
latest frontier used for the regression check. No inherited score gain is
claimed as this run's discovery. The old rank-13 holder remains in the board,
although the new smaller curve now holds its cell.

## Search implementation and measured experiments

The native first sieve is submission/research/x400a-conductor-simd.cpp.
Its trace table is generated by x400a-prime-tables.gp. For every prime up to
2000 and every affine parameter residue, this table counts points over the
finite field. Singular residues receive zero weight in the search sum.
The score is a fixed-point approximation to
S(X)=sum_{prime<=X} a_prime log(prime)/prime, with scale128.
Smaller sums order candidates first; they are not certificates or scores.

The grid includes q=1,...,N and p=-N,...,N, followed by coprimality and
nonsingularity filtering. In particular, both signs were included in the
winning search. The code reports actual counter updates, before filtering,
rather than treating a printed domain formula as a measurement.
At N=10000 it processed200010000 pairs in8.96 seconds. A deeper prime sieve
retained8144 candidates, and8143 fresh rank checks plus one inherited
duplicate produced no improvement. The best new rank12 result in that
batch had height23.649257, above the current rank12 holder.

The wider run at N=60000 processed7200060000 pairs in346.182 seconds.
It produced23763 distinct preliminary candidates for deeper refinement.
The GP refinement computed minimal models, the sum through10000, the number
of small bad primes, and exact conductor logarithms. A union of two rankings,
one with a small-bad-prime adjustment and one with a conductor adjustment,
retained11858 models across the relevant target-rank buckets.
The rank search is limited per bucket and skips cached rigorous upper bounds
that are already below the improvement target. The winning run stopped after
2367 new rank checks, in126.2 seconds, when the positive curve was certified.
It does not claim that all grid curves had their ranks determined.

The preliminary height calculation is deliberately a lower bound. Common
scaling at the fixed resultant primes is removed, and an extra factor2 is
allowed before exact minimalization by GP. Thirty sampled finalists,
including15 negative numerators, matched the scalar integer sieve exactly.
Their height lower bounds were below the actual GP minimal heights, with
maximum gap log2. The evidence is in x400a-validation.json and the validation
source is validate-x400a.py.

For this family the difference factors as
A-B=(p-23q)(p-4q)(25p-11q)(74p-121q).
The fixed common-factor primes are2,3,5,7,11,17,19,23,41.
The first-stage conductor and bad-prime adjustments only order candidates;
the deeper GP stage computes exact quantities. Neither adjustment is part
of the challenge score.

## Deriving point seeds independently

The scripts x400a-sections.gp and x400a-all-sections.gp search symbolically
for sections whose x-coordinate is a rational constant times a product of
selected linear factors of A and B. For each split, the discriminant in the
parameter identifies rational constants that can make the curve equation a
polynomial square. Every retained identity is checked with exact polynomial
square testing. This produced24 polynomial sections in the tested class.

A height-matrix check at the fresh test parameter17/13 selected four
independent sections, with determinant179.5828515033053. All four points
were checked exactly on that curve. The generated x400a-family.gp evaluates
these sections at a new p/q and homogenizes x by q^4 and y by q^6.
The final search passes the resulting points, transformed to the minimal
model, to ellrank. The remaining points on the winning specialization were
found by GP; none came from an inherited point list.

Although the inherited header calls this a rank-5 family, this run only
derived and checked four independent generic section formulas. The final
submission does not rely on that generic-rank claim: all13 witnesses on the
actual winning curve are independently certified by the challenge verifier.

## Reproduction

Run from the repository root after the normal challenge setup. The sources
for the winning sieve, refinement, section search and point search are kept
under submission/research. The following commands recreate the wide grid:

    tools/pari/bin/gp -q submission/research/x400a-prime-tables.gp > /tmp/ec-rank-x400a-prime-tables.txt
    g++ -O3 -march=native -fopenmp submission/research/x400a-conductor-simd.cpp -o /tmp/ec-rank-x400a-simd
    /tmp/ec-rank-x400a-simd 60000 10 > /tmp/ec-rank-x400a-wide-shortlist.txt
    .venv-bench/bin/python submission/research/refine-x400a-wide.py
    .venv-bench/bin/python submission/research/search.py --input sieve-x400a-wide.txt --limit 3000

The saved initial-board.json fixes the parent contributions used by the
search. Local completed-check caches affect repeated work and search order,
but are never accepted as verification evidence. Large generated
intermediates were moved out of the public submission to stay well below
the platform's16MiB editable-tree cap. Their sizes and SHA-256 hashes are
recorded in archived-intermediates.json. These intermediates are not needed
to verify the submitted curve.

A faster, self-contained reproduction of the actual result uses the family
equations and fresh seeded GP point search, without any sieve cache:

    .venv-bench/bin/python submission/research/reproduce-winner.py

This command regenerated bounds[13,13] and exactly the same13 rational
witnesses, then passed the official verifier with novelty checking enabled.
winner-reproduced.json records that verification. The original winning
candidate and search output are in discovery.json and winner-search-record.json.

The full scored board was checked with the current parent:

    .venv-bench/bin/python -m ec_verify submission/board --parent submission/research/frontier-109-board

It exited0. final-board-verified.json records total111.9791058985735,
parent_total109.84323118123126, parent_gate=checked and a nonempty
improvements list containing only2x2/13.

## Verification evidence and limits

The new curve passes exact point membership, minimality, novelty against the
frozen ledger, and the full board duplicate gate. Thirteen submitted points
remain after torsion stripping; none is dropped. The smallest canonical
height-pairing eigenvalue is1.9357721388454288. The agreement between the
two prescribed height precisions is7.137051761873386e-56, comfortably inside
the verifier's required tolerance. The regulator lower bound is
1707984268136408.2. The board regression gate preserves every inherited cell.

Earlier experiments in this run included universal Tate-family sieves,
published rank-4 cyclic-4 families, a published cyclic-2 K3 family, several
own cyclic-3 constructions, and wide universal families with torsion4x2 and6x2.
None yielded this submission's gain. The full4 scan covered179999700000
counter pairs at N600000, followed by5119514652 boundary pairs; its finalists
did not improve the tested cells. A corrected full6 signed scan covered
45000150000 actual counter pairs in233.472 seconds;3977 new rank checks
and4 known-curve rejections also produced no improvement.

An initial full6 port had mistakenly retained a triangular positive domain
while printing a square-domain count. That coverage claim was discarded,
the loop was corrected to include both signs, and scalar and GP comparisons
were rerun before the corrected scan. The false coverage count is not used
as evidence. Valid individual earlier GP bounds were retained as a cache.

The search is heuristic and finite. It establishes an improvement for this
curve, not global optimality of any height record or exhaustive certification
of all parameters. Future work could expand the family search, strengthen
the first sieve, or obtain more independent sections. This submission's
purpose is a small, reproducible positive contribution and a first promoted
leaderboard entry.

The challenge's rules permit specializing a published family at a fresh
parameter. A consulted background source for the earlier family search was
Dujella and Peral, High rank elliptic curves with torsion Z/2Z x Z/4Z induced
by Diophantine triples:
https://web.math.pmf.unizg.hr/~duje/pdf/Z2Z4.pdf .
No particular curve from that paper was submitted here. Research discussions
for this benchmark reported disabled, so no discussion post was attempted.
