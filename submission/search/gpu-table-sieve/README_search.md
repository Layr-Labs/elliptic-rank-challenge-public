# GPU table sieve for Kubert torsion families (own code)

All code in this directory is our own. It implements the Mestre-Nagao sieve (Mestre 1982, Nagao 1992) on the one-parameter
Kubert/Tate families E(b,c): y^2 + (1-c)xy - by = x^3 - bx^2 with a rational torsion subgroup of order N (Z/5, Z/6, Z/8, Z/2xZ/4 ...),
t = p/q, followed by PARI/GP 2.17.4 `ellrank` + `ellsaturation` on the survivors.  No curve, parameter or table was copied from another
participant, ICARM, Dujella's tables, the LMFDB or the literature; published *methods* are credited in the submission note.

## Files

| file | role |
|---|---|
| `famgen.gp`, `fams.txt` | integral homogeneous models a_i(p,q) = q^(i d) A_i(p/q) of the families (Kubert's parametrisations), generated by PARI |
| `kub.c` | shared C code: family loader, per-prime tables tab_l[tau] (tau = t mod l, int8 of round(8 * -a_l log l / l)), height of the integral model, exact S(300)/S(2000)/S(10^4) on the host, CPU sieve (reference, 5e8 candidates/s/core) |
| `kubg.cu` | GPU driver: for a fixed q the parameter p runs through an arithmetic progression, so tab_l[(p q^-1) mod l] is periodic in p; stage 1 sums the 61 primes below 300 for 4 candidates per 32-bit word (SWAR byte lanes, shared-memory windows), stage 2 (primes 300..2000) is done per surviving candidate by a warp with an early exit at S(700); the host recomputes S(300), S(2000), S(10^4) exactly and applies the thresholds |
| `tabx.cu` | builds on the GPU the raw integer tables a_l(E_tau) for all primes 10^4 < l < 10^5 (finite-difference character sums, bit-packed quadratic-residue table in shared memory, 2 minutes for a family) and evaluates dS = S(10^5) - S(10^4) on the host in 0.5 ms; `KUB_THR4` adds the cut S(10^5) >= THR4 |
| `kub_rank.gp` | rank stage: `ellminimalmodel`, `elltors`, optional root-number parity screen (`KUB_WSIGN`), `ellrank(E,1)`, `ellsaturation`, writes the `.ec` file with the independent points |
| `pipe.sh`, `campaign.sh`, `inc_rank.sh`, `inc_loop.sh` | shell driver: height-ordered shells, sieve -> rank -> `ec_verify` screen, incremental ranking while the sieve runs |

## Families used

| FAM | curve | parameter | notes |
|---|---|---|---|
| 5, 6 | Kubert/Tate normal forms of Z/5 and Z/6 | t = p/q | integral models [a1,a2,a3,0,0]; symmetry t -> -1/t for Z/5 (|p| <= q) |
| 8, 10, 12, 26, 28, 7, 9 | Z/8, Z/10, Z/12, Z/2xZ/6, Z/2xZ/8, Z/7, Z/9 | t = p/q | thin-family scans only (no new record) |
| 42 | Z/2xZ/4 in Tate form [4q, q^2-16p^2, 4q(q^2-16p^2), 0, 0] | t = p/q | wasteful enumeration (every curve twice, 2-power scaling), used only for the first pilot |
| 44 | Z/2xZ/4 in Legendre form y^2 = x (x + a^2)(x + b^2) = [0, a^2+b^2, 0, a^2 b^2, 0] | coprime a > b >= 1 (kernel p = b, q = a) | every curve once; minimal height = H_F - ln 2 for the third of the pairs whose even element is divisible by 4, otherwise H_F; `fams.txt` blocks A4/A6 are optional extras read by the generalised loader |

The 2-division structure behind FAM 44: with r = q-4p, s = q+4p the Tate model of FAM 42 is isomorphic to y^2 = x(x+r^2)(x+s^2); (a,b) = (r,s)/gcd up to order and sign, so t and 1/(16 t) give the same curve.

## Outer-value restriction (`KUB_QRICH`, `KUB_ROLE`)

High-rank curves have many small bad primes (rank is bounded by the Selmer rank, which grows with the number of primes of bad reduction). Counting, for the sieve's own rank >= 7 survivors, the primes of W = {7, 11, ..., 47} that divide each discriminant factor showed the enrichment sits in the factors of high exponent (Legendre Z/2xZ/4: a, b; Z/5: p, q; Z/6: p and p+q; Z/8: p and q-p). `kubg` therefore has an optional filter: the outer value q of the (q, p-range) loop is skipped unless at least t primes of W divide it (`KUB_QRICH=t`), the inner values p stay dense, so the GPU kernels are unchanged. The family symmetry (Legendre: a <-> b; Z/5: t -> -1/t, `KUB_ROLE=B`) or unimodular re-coordinatisations written into `fams.txt` (FAM 66 = Z/6 with outer p, FAM 67 = Z/6 with outer p+q, FAM 88 = Z/8 with outer p; `famsubst.gp` generates such variants) make every high-exponent factor an outer value. t = 3 keeps 55 % (Legendre Z/2xZ/4) to 76 % (Z/5) of the rank >= 7 curves that the dense sieve finds, in 3.4 % of the pairs; on test shells the filtered output equals the dense output restricted to the same rule (`ladder.sh`, `hi_scan.sh`, `watch_ec.sh` are the bookkeeping scripts). The filtered sweeps are therefore not exhaustive.

## Method in five lines

1. For every t = p/q in lowest terms (symmetries removed: |p| <= q for Z/5, p <= q/2 for Z/8) with the naive height of the integral model in the shell,
   S(X) = sum_{l <= X} -a_l(E_t) log(l)/l is accumulated from the per-prime tables.
2. Cuts on S(300), S(2000), S(10^4) (and S(10^5) for the extended tables) were calibrated on the frozen record curves of the family;
   the unit tests of the sieve are the re-discovery of those records (Z/5 ranks 6-9, Z/6 ranks 6-9, Z/2xZ/4 ranks 8-9, Z/8 ranks 4-6) and byte-identical output of
   successive kernel versions on fixed ranges.
3. Survivors go through `kub_rank.gp`; a curve with rank lower bound >= the target is saturated and written as `.ec`.
4. `python -m ec_verify` (novelty gate on) is run on every such file; the frozen records are rejected as `KNOWN_CURVE`.
5. Logs (candidate lists per shell, ranked lists, thresholds, binaries' sources) are kept for the post-competition audit.

## Reproduce

```
KUB_FAMS=fams.txt ./tabx_build build 5 tabs 10000 100000          # extended tables (GPU)
KUB_TABDIR=tabs KUB_FAMS=fams.txt KUB_THR4=55 KUB_HMIN=<Hlo> ./kubg sieve 5 <Hhi> 1 1000000000 9.5 24 34 6 > cand.txt
KUB_FAM=5 KUB_IN=cand.txt KUB_MINRANK=9 gp -q kub_rank.gp
python -m ec_verify submission/board/<file>.ec
```

## Update for the second Legendre find (submission after `d7c737f3`)

* `logs/winning_run_2/` holds the candidate list, ranked list, verifier screen and sieve head/tail of the shell that produced the curve of cell 4x2/9 with (a,b) = (184873649, 51731680) (role B, `KUB_QRICH=4`, integral-model shell [19.51, 20.0)); `command.txt` is the exact campaign command.
* Shell edges are defined on the height of the *integral* Legendre model, the score on the *minimal* model: for the third of the pairs whose even element is divisible by 4 the minimal height is lower by ln 2 (0.693), so these pairs are scored 0.693 below the shell they were swept in.
* `src/kub.c`, `src/kubg.cu`, `src/fams.txt`, `src/kub_rank.gp` now also contain FAM 4 (Z/4 in Tate form, t = p/q, integral model [q, -pq, -pq^2, 0, 0], discriminant p^4 q^7 (16p+q)): a wider height grid for tau up to 1e18 (only for FAM 4, the grid of all other families is unchanged), a larger work-item buffer (MAXITEMS 2^20) with an explicit capacity check instead of silent dropping, and the skip of the singular fibre t = -1/16. The binaries that produced the finds were built from the version without these additions; the code path of FAM 44 is identical.
